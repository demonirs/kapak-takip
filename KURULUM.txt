KAVİS — İstanbul yetki düzeltmesi, aşama 1 (01.10.2026)

Bu paket yalnızca aşağıdaki dosyaları içerir:
src/App.tsx
src/components/Layout.tsx
src/components/MainWarehouse.tsx
src/components/Users.tsx
src/lib/permissions.ts (yeni)
sql/KAVIS_Istanbul_004_yetkiler.sql (yeni)

1. Mevcut dört TSX dosyasını proje DIŞINDA bir klasöre kopyalayarak yedekleyin.
2. ZIP içindeki src ve sql klasörlerini KAVIS-Unified içine kopyalayın.
3. CMD'de npm run check çalıştırın. Çıktıyı paylaşın.
4. Kontrol başarılı olduktan sonra SQL yalnızca İstanbul Supabase projesinde uygulanır.
   SQL transaction içindedir: hata oluşursa COMMIT çalıştırmayın; ROLLBACK; çalıştırın.
5. npm run dev ile yetkileri test edin.

Test matrisi:
Ankara: Ana Depo menüde yok; doğrudan /main-warehouse erişimi yok.
İstanbul member: vaka ekleme/düzenleme mevcut; Ana Depo menü/sayfa/API erişimi yok.
İstanbul depo: vakaları görüntüler; /add, /edit/:id, /foc/:vakaId ve rakip vaka
sayfasına erişemez; vaka/FOC oluşturan RPC çağrıları da reddedilir.
İstanbul depo_viewer: klinik vaka yetkileri mevcut; Ana Depo okur, stok değiştiremez.
İstanbul admin: depo stok girişi/çıkışı ve rol yönetimi mevcut.
Member kendi profil rolünü değiştirmeyi denediğinde mevcut trigger reddetmelidir.
Barkod iki defa okutulunca adet 2 olmalı; yetersiz stok çıkışı reddedilmeli.
